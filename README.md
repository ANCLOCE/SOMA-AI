# Полностью оффлайн ИИ-ассистент

Этот проект представляет собой модульного, кроссплатформенного и полностью оффлайн работающего ИИ-ассистента. Он поддерживает русский и английский языки, голосовой и текстовый ввод, а также способен самообучаться на предоставленных пользователем данных (текстовых файлах).

Архитектура системы описана в файле `ARCHITECTURE.md`.

## Возможности

*   **100% Оффлайн**: Все компоненты, включая модели, работают локально без доступа к интернету.
*   **Модульная структура**: Система построена на плагинах, общающихся через шину событий. Это позволяет легко модифицировать или заменять компоненты.
*   **Самообучение (RAG)**: Ассистент может индексировать текстовые файлы (`.txt`, `.pdf`) и использовать полученные знания для ответов на вопросы.
*   **Кроссплатформенный UI**: Интерфейс написан на Flet и работает на Windows, Linux и macOS. (Для Android требуется дополнительная сборка).
*   **Двуязычность**: Поддерживаются русский и английский языки (требуются соответствующие модели).

## 1. Установка окружения

### Шаг 1: Клонирование репозитория
```bash
git clone <repository-url>
cd <repository-folder>
```

### Шаг 2: Создание виртуального окружения (рекомендуется)
```bash
python3 -m venv venv
source venv/bin/activate  # Для Linux/macOS
# venv\Scripts\activate   # Для Windows
```

### Шаг 3: Установка зависимостей
Все необходимые Python-библиотеки перечислены в `requirements.txt`.
```bash
pip install -r requirements.txt
```

## 2. Загрузка моделей

Для работы ассистента требуются оффлайн-модели в формате GGUF.

### Шаг 1: Создайте папку для моделей
```bash
mkdir models
```

### Шаг 2: Скачайте необходимые модели и поместите их в папку `models`

**1. Модель для эмбеддингов (обязательно для функции самообучения)**
Эта модель нужна для работы плагина знаний (RAG).
*   **Модель**: `bge-small-en-v1.5` (quantized)
*   **Ссылка**: [bge-small-en-v1.5-q4_k_m.gguf](https://huggingface.co/TheBloke/bge-small-en-v1.5-GGUF/resolve/main/bge-small-en-v1.5-q4_k_m.gguf)
*   **Имя файла**: Убедитесь, что файл сохранен как `models/bge-small-en-v1.5-q4_k_m.gguf`. Именно это имя ожидает плагин `knowledge_plugin.py`.

**2. Языковая модель (LLM) (обязательно для генерации ответов)**
Вы можете выбрать любую GGUF-совместимую модель. Мы рекомендуем следующие:
*   **Для русского языка**: `Saiga-Mistral 7B`
    *   **Ссылка**: [model-q4_K.gguf](https://huggingface.co/IlyaGusev/saiga_mistral_7b_gguf/resolve/main/model-q4_K.gguf)
*   **Для английского языка и кода**: `Mistral-7B-Instruct-v0.2`
    *   **Ссылка**: [mistral-7b-instruct-v0.2.Q4_K_M.gguf](https://huggingface.co/TheBloke/Mistral-7B-Instruct-v0.2-GGUF/resolve/main/mistral-7b-instruct-v0.2.Q4_K_M.gguf)

**Важно**: Логика использования LLM в `llm_plugin.py` на данный момент является заглушкой. Вам нужно будет раскомментировать и адаптировать код в `llm_plugin.py`, указав путь к скачанной LLM-модели.

## 3. Запуск приложения

После установки зависимостей и загрузки моделей вы можете запустить приложение.

```bash
python3 main.py
```

Откроется окно с графическим интерфейсом чата.

## 4. Как использовать и тестировать

### Тест 1: Обычный диалог
1.  Запустите приложение.
2.  Дождитесь сообщений в консоли о том, что плагины загружены.
3.  Введите любой вопрос в текстовое поле и нажмите "Отправить".
4.  Вы должны получить ответ-заглушку от LLM-плагина.

### Тест 2: Функция самообучения (RAG)
Этот тест проверяет всю цепочку: загрузка файла -> индексация в базе знаний -> ответ на основе содержимого файла.

1.  **Подготовка**: Убедитесь, что вы скачали и разместили модель для эмбеддингов в `models/bge-small-en-v1.5-q4_k_m.gguf`.
2.  **Создайте тестовый файл**: Создайте файл `test.txt` с каким-нибудь уникальным текстом. Например:
    ```
    Секретный ингредиент для кибер-блинов - это квантовый сироп.
    ```
3.  **Запустите приложение**.
4.  **Загрузите файл**:
    *   Нажмите на иконку скрепки (Загрузить файл).
    *   Выберите ваш `test.txt`.
    *   В чате появится системное сообщение о начале загрузки, а затем о ее завершении.
5.  **Задайте вопрос**: Введите в чат вопрос, ответ на который есть только в файле. Например:
    > Какой секретный ингредиент для кибер-блинов?
6.  **Проверьте ответ**: Ассистент должен ответить, используя информацию из файла: `Секретный ингредиент - 'квантовый сироп'`. (Ответ может немного отличаться в зависимости от LLM).
